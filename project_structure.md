# Project Structure

## configs
Stores configuration files such as training parameters and inference settings.

## datasets
Contains the NEU Metal Surface Defects dataset.

- raw/
- processed/
- sample/

## docs
Project documentation.

## exports
Exported ONNX and TensorRT models.

## inference
Inference scripts for image and video prediction.

## models
Model architecture and checkpoints.

## notebooks
Experimental notebooks and exploratory analysis.

## results
Training logs, evaluation reports, and benchmark results.

## scripts
Automation and utility scripts.

## tests
Environment and unit tests.

## training
Training-related scripts.

## utils
Shared helper functions.

## weights
Trained model weights.
